## 1. Project Overview

This project implements regression and classification models using the UCI Productivity Prediction of Garment Employees dataset.

The lab contains two implementations:

1. Machine Learning using Scikit-learn
2. Machine Learning implemented from scratch using NumPy and Pandas

The implementations are compared based on predictive performance and execution time. The manual Logistic Regression implementation is also optimized using different learning rates and numbers of iterations.
